# 参考资料整合说明

本目录是书稿编写时使用的本地资料库，不等同于书稿正文里的“正式参考文献”。

## 分层原则

- `主线资料`：能直接支撑 Spark 4.x 主线叙事的图书，优先服务于结构化处理、流处理、机器学习、应用交付和性能优化。
- `专题资料`：适合补平台、数据工程、湖仓、云环境或特定场景，不应替代 Apache Spark 通用事实。
- `历史资料`：适合解释 Spark 2.x、DStream、旧版 `spark.mllib` 和存量系统迁移，不进入现代主线。
- `噪声文件`：下载说明、宣传页、torrent 说明、请求文本等，不进入书稿。

## 使用边界

- 正文中的参考文献章只保留读者可直接使用的资料，不放整合计划、章节改写顺序和资料库缺口分析。
- 章节末尾可以补“延伸阅读”，但只写“读者接下来可以看什么”，不写“编辑接下来应该怎么改”。
- 平台专项资料如 Databricks、Dataproc、Delta Lake 只能作为专题补充，不能替代 Spark 官方文档与通用概念说明。
