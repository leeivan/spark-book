# 前言


## 0.1 学习建议（先易后难）
- 第1-4章先建立 Spark 全景和数据处理主线。
- 第5-6章理解流处理和图计算的典型场景。
- 第7-9章重点练习机器学习与特征工程。
- 第10-11章补齐工程化部署与性能优化能力。

## 0.2 一个学习节奏例子
如果你每周学习 3 次，每次 60 分钟：
1. 第1次：读概念 + 抄一遍最小代码。
2. 第2次：改参数并观察结果变化。
3. 第3次：把示例改成你自己的数据字段。

这样比“只看不练”更容易形成稳定的实战能力。

> **版本基线（更新于 2026-02-13）**
> 本书默认适配 Apache Spark 4.1.1（稳定版），并兼容 4.0.2 维护分支。
> 推荐环境：JDK 17+（建议 JDK 21）、Scala 2.13、Python 3.10+。

## 关于本书
Spark 已经从早期“以内存计算为卖点的分布式引擎”，演进为一套覆盖结构化处理、流处理、机器学习和工程部署的统一平台。对今天的大多数团队来说，真正高频的 Spark 能力不再只是 RDD 转换本身，而是如何围绕 `Spark SQL / DataFrame`、`Structured Streaming`、`spark.ml`、应用交付和性能调优形成完整工作流。

本书的目标不是罗列所有历史 API，而是帮助读者建立一条可落地的 Spark 4.x 主线：读数据、做结构化转换、处理批流任务、完成特征与建模、打包部署应用、再用监控与调优手段把它稳定运行起来。书中仍保留一部分历史内容，例如 RDD 深入、DStream、GraphX 和 `spark.mllib` 风格接口；这些内容主要用于解释 Spark 的演进路径、阅读存量系统和理解迁移判断，而不是作为新项目默认模板。

本书也尽量把教学视角和工程视角放在一起：既给出概念与 API，也保留最小示例、运行方式、案例分析和部署调优内容，帮助读者把知识从“会看”推进到“能做”。

## 本书结构

除概览与前言外，正文按 12 章组织：

- 第1章从平台与生态视角介绍 Spark 在现代数据系统中的位置，明确哪些能力属于主线，哪些属于历史背景或专题组件。
- 第2-4章建立基础认知，包括执行模型、RDD 与分区、以及 `Spark SQL / DataFrame / Dataset` 的结构化处理主线。
- 第5章聚焦流处理，重点讲 `Structured Streaming`，并把 DStream 作为历史兼容内容处理。
- 第6章介绍图处理，并把 GraphX 放在专题能力的位置上理解。
- 第7-9章围绕机器学习、特征工程和算法索引展开，其中主线是 `spark.ml + DataFrame + Pipeline`，旧式 `spark.mllib` 接口主要用于历史对照。
- 第10-11章补齐工程化能力，包括应用打包、提交、部署、监控和性能优化。
- 第12章整理官方文档与系统学习资料，方便持续扩展。

## 读者对象

本书适合以下读者：

- 希望系统入门 Spark 4.x 的初学者。
- 需要把零散 Spark 知识整理成完整工程主线的开发者。
- 需要兼顾教学、培训和内部知识传递的教师或技术负责人。
- 正在维护旧 Spark 系统，希望区分“现代主线”和“历史兼容写法”的工程团队。
