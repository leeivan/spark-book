# 0.1 怎么读这本书（通俗版）

先看每章开头的“最小例子”，把概念和代码先建立直觉；再按“概念 -> API -> 实战”的顺序阅读，不必一次看完所有细节；学习时建议边看边在本地 `spark-shell` 或 `pyspark` 里复现。

## 这本书的主线是什么

新项目优先使用 `SparkSession + DataFrame` 处理结构化数据；流处理优先理解 `Structured Streaming`，`DStream` 主要作为历史兼容内容阅读；机器学习优先理解 `spark.ml + Pipeline`，`spark.mllib` 主要用于旧代码和历史 API 对照；部署、监控与优化不是附录内容，而是完成 Spark 工程闭环的主线能力。
