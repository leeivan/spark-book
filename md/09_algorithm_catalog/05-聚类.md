# 9.5 聚类

聚类任务在 Spark 4.x 中同样优先采用 `spark.ml` API。本节以 K 均值、LDA、二分 K 均值和高斯混合模型为代表，重点说明适用场景、输入输出列和最小示例。

### 9.5.1 K 均值

K均值（k-means）是最常用的聚类算法之一，它将数据点划分到预定数量的簇中。Spark 的 `KMeans` 估算器使用适合分布式训练的初始化策略，并生成 `KMeansModel` 作为结果模型。在工程实践中，它通常适合作为无监督学习的第一条基线。

### 9.5.2 潜在狄利克雷分配（LDA） 

LDA 在 Spark 中被实现为一个估算器，可根据数据规模与训练方式选择 `EMLDAOptimizer` 或 `OnlineLDAOptimizer`，并输出 `LDAModel`。对大多数读者来说，真正需要理解的是它解决的问题：不是把样本硬分进某个簇，而是为每篇文档学习“主题分布”，再为每个主题学习“词分布”。如果需要做更细的底层分析，还可以把部分模型进一步转成 `DistributedLDAModel`。

LDA 的输出除了可用于查看每个文档的主题分布，也可以反过来检查每个主题更偏好的词项。

LDA（Latent Dirichlet Allocation）是一种经典的主题模型。可以把它理解成一个三层概率结构：文档由若干主题按不同比例混合而成，而每个主题又对应一组更容易共同出现的词。所谓“生成式”视角，就是把一篇文档中的词看成先抽到某个主题，再从该主题里抽到具体词语的结果。

在工程上，LDA 的意义不在于得到一个“绝对正确”的主题标签，而在于帮助我们用无监督方式发现大规模文档集中的潜在结构。它通常建立在词袋表示之上，把每篇文档视为词频向量，因此不会显式考虑词序。这样做牺牲了部分语义细节，但换来了可扩展的建模方式，也让“文档 - 主题分布”和“主题 - 词分布”这两层结果变得易于解释。

### 9.5.3 二分 K 均值

二分 K 均值是一种使用分裂（或“自上而下”）方法的分层聚类：所有观测都先落在一个簇中，然后递归地继续拆分。它通常比常规 K 均值更适合层次化理解聚类结构，但得到的结果与普通 K 均值并不完全相同。`BisectingKMeans` 作为估算器实现，并生成 `BisectingKMeansModel` 作为基础模型。

```scala
scala> import org.apache.spark.ml.clustering.BisectingKMeans
import org.apache.spark.ml.clustering.BisectingKMeans
```

### 9.5.4 高斯混合模型

高斯混合模型把数据看成由多个高斯子分布混合而成，每个子分布都有自己的均值、协方差和权重。`spark.ml` 使用 EM 算法在给定样本上估计这一模型。相比 K 均值，它更适合描述“簇是椭球形且重叠”的场景。

#### 9.5.4.1 输入列 

| 参数名称        | 类型     | 默认         | 描述   |
| ----------- | ------ | ---------- | ---- |
| featuresCol | Vector | "features" | 特征向量 |

表格 9‑12 输入列

#### 9.5.4.2 输出列 

| 参数名称           | 类型     | 默认            | **描述**  |
| -------------- | ------ | ------------- | ------- |
| predictionCol  | Int    | "prediction"  | 预测簇索引 |
| probabilityCol | Vector | "probability" | 属于各混合成分的后验概率 |
