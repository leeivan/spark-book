内容简介

本书以 Apache Spark 4.x 为基线，对 Spark 应用开发的核心概念、主线能力和工程实践进行了系统梳理。全书优先讲解 `Spark SQL / DataFrame`、`Structured Streaming`、`spark.ml`、应用部署和性能优化；同时保留少量 RDD、DStream、GraphX 和 `spark.mllib` 的历史内容，用于帮助读者理解执行模型、阅读存量代码和判断迁移路径。

本书适合 Spark 初学者、需要建立完整知识框架的工程开发者，也适合作为高校课程、内部培训和团队学习材料。

> **版本基线（更新于 2026-02-13）**
> 本书默认适配 Apache Spark 4.1.1（稳定版），并兼容 4.0.2 维护分支。
> 推荐环境：JDK 17+（建议 JDK 21）、Scala 2.13、Python 3.10+。

## 0.1 怎么读这本书（通俗版）
- 先看每章开头的“最小例子”，把概念和代码先建立直觉。
- 再按“概念 -> API -> 实战”的顺序阅读，不必一次看完所有细节。
- 学习时建议边看边在本地 `spark-shell` 或 `pyspark` 里复现。

## 0.2 这本书的主线是什么
- 新项目优先使用 `SparkSession + DataFrame` 处理结构化数据。
- 流处理优先理解 `Structured Streaming`，`DStream` 主要作为历史兼容内容阅读。
- 机器学习优先理解 `spark.ml + Pipeline`，`spark.mllib` 主要用于旧代码和历史 API 对照。
- 部署、监控与优化不是附录内容，而是完成 Spark 工程闭环的主线能力。

## 0.3 一个最小例子
假设你有一份订单数据，想快速算出“每个城市的订单数”：
1. 读入数据（CSV/Parquet）。
2. 按城市分组。
3. 做 `count` 聚合。
4. 输出结果并观察是否符合业务直觉。

这就是本书很多示例的基本模式：读数据、变换、聚合、输出。
