# 4.5 小结

Spark SQL 是 Spark 4.x 处理结构化数据的主线模块。它在 RDD 之上增加了列、类型、Schema 和表达式语义，使 Catalyst 和 Tungsten 能够做更稳定的优化，并且更容易与 Catalog、元数据服务和现代数据平台协同工作。对大多数工程场景而言，DataFrame 是默认入口；Dataset 适合 Scala / Java 中确实需要类型安全的场景；RDD 则保留给更底层、更定制化的处理需求。本章的重点并不是记住所有 API 细节，而是建立一种稳定判断：什么时候应该优先使用结构化表达式、为什么 Schema 会直接影响优化效果，以及如何把查询、聚合、窗口和 Join 放回同一套执行模型里理解。
