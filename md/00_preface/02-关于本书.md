# 0.2 关于本书
Spark 已经从早期“以内存计算为卖点的分布式引擎”，演进为一套覆盖结构化处理、流处理、机器学习和工程部署的统一平台。对今天的大多数团队来说，真正高频的 Spark 能力不再只是 RDD 转换本身，而是如何围绕 `Spark SQL / DataFrame`、`Structured Streaming`、`spark.ml`、应用交付和性能调优形成完整工作流。

本书的目标不是罗列所有历史 API，而是帮助读者建立一条可落地的 Spark 4.x 主线：读数据、做结构化转换、处理批流任务、完成特征与建模、打包部署应用、再用监控与调优手段把它稳定运行起来。书中仍保留一部分历史内容，例如 RDD 深入、DStream、GraphX 和 `spark.mllib` 风格接口；这些内容主要用于解释 Spark 的演进路径、阅读存量系统和理解迁移判断，而不是作为新项目默认模板。

本书也尽量把教学视角和工程视角放在一起：既给出概念与 API，也保留最小示例、运行方式、案例分析和部署调优内容，帮助读者把知识从“会看”推进到“能做”。
