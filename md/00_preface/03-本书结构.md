# 0.3 本书结构

&emsp;&emsp;除概览与前言外，正文按 12 章组织：

- 第1章从平台与生态视角介绍 Spark 在现代数据系统中的位置，明确哪些能力属于主线，哪些属于历史背景或专题组件。
- 第2-4章建立基础认知，包括执行模型、RDD 与分区、以及 `Spark SQL / DataFrame / Dataset` 的结构化处理主线。
- 第5章聚焦流处理，重点讲 `Structured Streaming`，并把 DStream 作为历史兼容内容处理。
- 第6章介绍图处理，并把 GraphX 放在专题能力的位置上理解。
- 第7-9章围绕机器学习、特征工程和算法索引展开，其中主线是 `spark.ml + DataFrame + Pipeline`，旧式 `spark.mllib` 接口主要用于历史对照。
- 第10-11章补齐工程化能力，包括应用打包、提交、部署、监控和性能优化。
- 第12章整理官方文档与系统学习资料，方便持续扩展。
